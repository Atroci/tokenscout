## [0.0.0] - 2026-06-04

### Added

- Initial scaffold: zero-dependency TypeScript design-token toolkit (ESM, Node 20+).
- Color module (`tokenscout/color`): CSS color parsing (`parseColor`), sRGB to
  CIELAB conversion (`rgbToLab`), ΔE76 distance (`deltaE76`), and perceptual
  color clustering via single-linkage union-find (`clusterColors`).
